## Forward-compat policy (docs/api-stability.md)
- Additive fields (ops, dialects, refusal codes, limits, enum values) do not bump ABI_VERSION or the schema id.
- Removing or retyping a field is breaking and needs an ABI_VERSION bump.
- `enum` lists are informational; hosts treat an unknown refusal code as a refusal.
- Hosts must check `abi_version` equals the version they were written against.
- A crate calendar break without an ABI break ships a new digest pin, not an ABI_VERSION bump.
- Public error enums use wildcard arms; adding a field to the listed public structs is breaking.
- Deprecations last at least one full minor release. cargo-semver-checks runs in CI job `semver`.
